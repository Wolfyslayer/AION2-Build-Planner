# Metaroad as an external AION 2 reference

Source: https://metaroad.gg/aion2/database

Metaroad publishes client-derived class, skill and Daevanion information. Its Terms of Service at https://metaroad.gg/terms-of-service prohibit automated scraping without permission (reviewed 2026-10-23).

This repository currently links to Metaroad class and skill pages as references. It does **not** scrape, bulk reproduce, mirror, or bundle its data or artwork.

Important modeling distinction: variant counts are not skill-rank costs. A source showing 26 variants does not justify generating 26 skill ranks or assigning point costs. Specialisation thresholds are separate from skill level requirements. Missing data must stay unknown.

To enable curated data ingestion, obtain explicit permission or a separately licensed source, identify the game client patch and region, and map exact IDs/ranks/costs/prerequisites into the existing verified catalog schema. Maintain provenance and patch-specific tests.
